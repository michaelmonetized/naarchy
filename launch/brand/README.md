# Naarchy identity

Cobalt `#3035FF`. Lime `#D5FE6B`. Warm white `#F7F6EE`. Ink `#10110F`.

The N uses the same rounded geometry as Naarchy's island. A lime light marks the place where work is ready to pick up. Keep the mark upright. Leave at least the width of one stem around it. Use the complete tile for app icons and the white mark on cobalt for large compositions.

`naarchy-logo.oma` is the editable original. The Lua plugin creates five native shapes inside Omadesign. SVG and PNG are Omadesign exports. Run the plugin through Plugins → Manage plugins → Naarchy launch identity → Create Naarchy mark, or use the documented CLI. Source geometry is original work created for this launch.
